# Sign Labels

**Give your arrow signs — and six other signs — a label of their own.**

Core Keeper's text sign already lets you write on it. The placeable arrow
doesn't, and neither do the skull, brute, warning and wooden signs — so
marking a waypoint with an arrow has always meant planting a separate text
sign right next to it. Sign Labels fixes that: interact with any of these
seven signs and the game's own sign window opens, exactly like it does on a
text sign.

## Features

- Seven signs get a label, edited in the game's own sign window — text,
  visibility toggle, parental filter and controller support all included:
  - Arrow Sign (*Richtungsschild*)
  - Skull Effigy (*Schädel-Schild*)
  - Brute Sign (*Schläger-Schild*)
  - Yellow Warning Sign (*Gelbes Warnschild*)
  - Red Warning Sign (*Rotes Warnschild*)
  - Wooden Sign "Core" (*Holzschild „Kern"*)
  - Wooden Sign "Tulip" (*Holzschild „Tulpe"*)
- Visibility per sign, same as the vanilla text sign: Off, only while
  targeted, or Always.
- A **Default visibility** option (Options → Mod settings → Sign Labels) sets
  what a freshly placed sign starts at — Off, Hover or Always, default Hover.
  Only your own placements are affected; a sign loaded from a save keeps its
  saved state.
- Mining a labelled sign always drops exactly one, whatever its visibility is
  set to.
- Works alongside **More Labels** — its hover option applies to these signs'
  labels too.

## Requirements

- CoreLib (required)
- Mod Settings Menu (required) — hosts the in-game settings screen

mod.io will prompt you to install both when you subscribe. Both are also
needed on the server side, so a server running this mod needs them installed
there as well.

## Good to know

- Verified on Core Keeper 1.3.0.4.
- The three signs that already have a vanilla label — the text sign, the
  metropolis sign and the excavation sign — are untouched.
- Holoboards (the small, large and broken info board) are not covered.
